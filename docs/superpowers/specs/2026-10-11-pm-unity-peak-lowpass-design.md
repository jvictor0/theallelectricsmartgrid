# PM low-pass with unity peak at the fundamental

The user approved an exponential actual -3 dB cutoff range of 2× to 128× fundamental (midpoint 16×), while preserving fundamental decay. Replace the fixed-Q Butterworth damper with a two-pole low-pass whose prototype magnitude peaks at unity exactly at the played fundamental. Its Q approaches Butterworth as the cutoff opens. At the closed endpoint in the low-frequency limit, Q is about 0.855124, DC is -0.457575 dB, fundamental gain is 0 dB, and a signal at twice the fundamental is -3.0103 dB per circulation. Neither endpoint bypasses; exact DECAY center remains dry.

For normalized fundamental f and requested prototype cutoff c=min(0.49,f*exp2(1+6*d)), prewarp both frequencies: t=tan(pi*f), v=tan(pi*c)/t. Let A=hypot(1,v*v-1), u2=1/A. Then g=t*sqrt(A), k=sqrt(2*(1-u2)), gain=sqrt((1-u2)*(1+u2)). The prototype is L(z)=gain*g²*(1+z^-1)² / ((1+k*g+g²)+2*(g²-1)*z^-1+(1-k*g+g²)*z^-2). These coefficients put the unity peak at f and the -3 dB point at c after bilinear warping. In analog normalized frequency u, |L|²=(1-u2²)/((u²-u2)²+1-u2²), so no prototype frequency exceeds unity.

Retain phase compensation at the fundamental, normalized allpass lattice, all radial memory factors, post-low-pass output including excitation, shared delay, and coalesced 5 ms transitions. The normalized peak gives the stationary prototype an undamped fundamental pole pair; H0(z/r) moves it to the selected decay radius while other modes can decay faster. This restores pitch/decay independence across DAMP without introducing loop gain above unity. It does not preserve upper-partial tuning: low cutoff creates dispersion and fast high-mode loss, which must be measured and documented.
