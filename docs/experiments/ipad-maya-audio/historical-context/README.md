# Historical context for journal citations

These files preserve source and protocol text cited by the dated journal from the former diagnostic worktree. They are archival evidence and are not production code or current build instructions. The source snapshot is the state available at journal preservation on September 28, 2026; it does not establish the exact contents of earlier installed binaries. Dated line citations may already have drifted before this snapshot.

Markdown links were made relative for portability. Non-Markdown files retain their original bytes. `source-manifest.json` records the original worktree-relative paths and hashes before link normalization. Original experimental code changes in the old worktree were not modified or landed into the app.
