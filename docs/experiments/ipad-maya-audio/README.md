## Separate the symptoms

**Sporadic interruptions:** recorded long gaps around 225–230 ms match MAYA input-endpoint transaction errors, driver I/O restarts and app callback arrival gaps. The error-to-restart chain is established; the initiating fault is not.

**Periodic blanking / SRR-like distortion:** repeated partial holes in analog output, even with the pure-tone callback. They can occur with regular app callback arrivals, short measured DSP time and unchanged native sample-timestamp counter. In the September 10 UI-off run, the pattern clears at a USB restart and returns near renewed drift accumulation. This supports a reset/masking hypothesis, not proof of one shared root cause. The later 8.0.15 run also recovered without a restart while reported drift kept rising, so recovery does not always require a reset.
